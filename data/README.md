# data/

- `joyo.txt` — the 2,136 Jōyō kanji (常用漢字表, 2010 Cabinet notice), one line, in code point order,
  using the official forms 𠮟 剝 頰 塡. Extracted from the `grade` field (1–6, 8) of
  [davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data) and checked to contain
  exactly 2,136 characters. Used by `reports/coverage.md`, `scripts/verify.py` and `scripts/make_webfonts.py`.
